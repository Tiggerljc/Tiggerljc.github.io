Lyra is only useful if you understand how it is built. Due to its modularity, the framework can become very complex to understand and debug, let alone build off of. It is crucial to understand not just where Lyra's content lives but also how to trace connections between different systems. This will allow you to use the framework confidently and efficiently.

File Structure

In order to maintain the project's modularity, Epic stored most of Lyra's content in Game Feature Plugins, rather than using the Content folder. This ensures a highly componentized workflow and enables the activation and deactivation of gameplay components at runtime.
