The Lyra Starter Game is a sample project designed by Epic Games to showcase Unreal Engine 5's modern gameplay architecture. It outlines the standard for multiplayer development in Unreal Engine using Modular Gameplay Plugins and the Gameplay Ability System. Lyra also comes with Epic Online Services (EOS) integration, allowing you to begin testing online features immediately.

Prerequisites

Lyra is incredibly powerful, but it is also incredibly dense and hard to navigate if you do not have a good foundation in Unreal Engine. Before using this documentation, you should be comfortable with the Unreal Editor as a whole. It is also recommended that you become familiar with Epic's official Lyra Documentation to provide a basis on which to interpret this massive project. This breakdown goes much deeper into Lyra, making it useful to have a more high-level overview before diving into the details.
