Format of a MLA Doc

  • Double-space
  • Times New Roman, Size 12
  • Header: Last Name, Page # (Top Right Corner)
  • First Page Only:
    • Author (Student)'s Name
    • Instructor's Name
    • Course & Section
    • Date

MLA Source Citations:
Author's last name, author's first name. "Title." Publisher, publication date, page numbers||URL.

Book with One Author:
Last Name, First Name. Title. Publisher, Date.
Book with Two Authors:
Last Name, First Name, and First name Last Name. Title. Publisher, Date.
Book with Three or More Authors:
Last Name, First name, et al. Title. Publisher, Date.

Hanging indents on sources longer than one line.

MLA In-Text Citations:
(Author's last name Page number)
If no author: ("Title" page number)
If no page number: (Author) || ("Title")
Period comes after citations, not before. Any information from an outside source must be cited. No copy/pasting, always quotes. Paraphrases must also be cited. Paraphrases from multiple pages must be cited as thus:
(Author pg., pg., pg., etc.)
