Lyra has multiple Editor-level plugins, mostly in the form of Game Feature Plugins (GFPs). This is due to Lyra's modular architecture, which prefers to put content into plugins. Using GFPs has the added benefit of allowing entire game systems to be activated and deactivated at runtime, further componentizing the project. This page goes over the Editor side of Lyra's core plugins.
